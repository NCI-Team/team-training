# Goals

* The trainee understands the concept of **Contracts** in Cisco ACI.
* The trainee understands how **Contracts control communication** between EPGs (Endpoint Groups).
* The trainee is familiar with **Subjects**, **Filters**, and the role of **Directional Communication** in Contracts.

---

## Tasks

* What is a **Contract** in ACI, and what is its primary purpose?

* What is the difference between a **Subject** and a **Filter** within a Contract?

* Read about **Contract Scope** and how it affects communication between EPGs.

* Read about **Preferred Groups** and **vzAny**.

* Read about how ACI enforces security policies using Contracts.

* What is the difference between **Provider** and **Consumer** roles in a Contract?

* What does **Contract Scope** mean, and what are the different types (VRF, Global, etc.)?

* What is the function of a **Filter Entry** inside a Contract?

* How do **Preferred Groups** impact Contract behavior?

* What is **vzAny**, and how is it used?

* How would you allow **EPG-to-EPG communication** using a Contract?

* Can multiple Contracts be applied between the same EPGs? If so, how is behavior determined?

* What happens if no Contract is defined between two EPGs?

* Can you configure a Contract to allow only **TCP port 443** traffic? How?

* How does **directionality** (bi-directional, uni-directional) work in Contract Subjects?
